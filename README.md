# עורך החפיסה — סופר מנצקין

פרויקט עצמאי. אין לו שום קשר לפרויקט המשחק ואפשר להעלות אותו לחשבון נפרד.

---

## העלאה

1. פתחו repository חדש ב-GitHub עם החשבון המשותף
2. גררו לשם את ארבעת הקבצים: server.js, index.html, cards.json, package.json
3. Commit changes
4. ב-Render: New, Web Service, בחרו את ה-repository
5. Build Command: npm install
6. Start Command: node server.js
7. בחרו Free
8. Create Web Service

שלחו את הקישור לחבורה. כל אחד נכנס עם השם שלו.

---

## מה שונה מהגרסה הקודמת

הטקסט לא נחתך. אף פעם. הקלף גדל לפי מה שכתוב בו.

הגלילה לא קופצת. כשמישהו אחר עורך, המסך מתעדכן בלי לזוז.

יש מנעול. מי שנכנס לשדה מחזיק אותו, ואצל האחרים הוא נראה אפור עם השם שלו. המנעול משתחרר כשיוצאים, או לבד אחרי עשרים וחמש שניות.

כל שדה ניתן לעריכה. שם, טקסט, חדשות רעות, הערה, אמוג'י, רמה, אוצרות, דרגות, בונוס, משבצת, זהב, אאורה, פרופיל. שדה ריק מופיע ככפתור מקווקו להוספה.

השינוי שלכם מופיע מיד. שינוי של אחרים תוך שנייה־שתיים.

---

## על הסנכרון, במילים פשוטות

בגרסה הקודמת הדפדפן שאל את השרת כל שתי וחצי שניות אם משהו השתנה. עכשיו יש חיבור פתוח והשרת מודיע מיד.

למעלה במסך יש נקודה. ירוקה זה מחובר. אדומה זה מנותק, והוא מתחבר מחדש לבד.

לידה כתוב מי עוד נמצא כרגע.

---

## הסיכון החשוב ביותר

ב-Render החינמי הדיסק נמחק בכל פעם שמעלים גרסה חדשה של הקוד.

לכן העורך שומר גיבוי גם בדפדפן של כל אחד מכם. אם השרת יאבד קלפים, מי שייכנס יראה שאלה: בשרת יש פחות קלפים מבגיבוי שלך, לשחזר?

זו רשת ביטחון, לא תחליף. לחצו על ייצוא בסוף כל מפגש עבודה ושמרו את הקובץ.

---

## שליחה למשחק

כפתור שלח למשחק מוריד קובץ בשם cards.json.

העלו אותו ל-repository של פרויקט המשחק במקום הקובץ הישן, ו-Render יבנה מחדש לבד.

שני הפרויקטים נשארים נפרדים לגמרי. אין ביניהם שום חיבור אוטומטי.
